## Overview

KRNL is a free Lua script execution environment made for the Windows edition of Roblox. It allows users to run custom scripts inside the game for a broad range of modifications and automation tasks. Its uncluttered interface is intended to make script injection accessible to first-time users while remaining quick for experienced users.

The executor includes an automatically updating engine that tracks changes in the Roblox client, helping reduce the need for manual compatibility maintenance. A built-in hub provides access to more than 500 community scripts, ranging from basic quality-of-life adjustments to advanced gameplay changes. Together, the update system and script collection provide a convenient starting point for Roblox modding.

## Frequently Asked Questions

**Is KRNL safe for my computer?**  
KRNL is a third-party application that changes Roblox's runtime environment, so users are responsible for any resulting consequences. Before opening it, scan the executable with an antivirus product you trust.

**What happens after Roblox releases an update?**  
The automatic update engine is intended to deliver compatibility patches soon after major Roblox releases. Large client changes can still result in temporary downtime.

**How does the free version compare with paid executors?**  
KRNL provides a free option with a large script collection and a core feature set similar to many paid executors. Following major Roblox patches, updates may take somewhat longer to arrive.

**Could using KRNL result in a Roblox account ban?**  
Third-party executors are prohibited by the Roblox Terms of Service, and account action is always possible. Use the software responsibly and avoid clearly abusive behavior in public servers.

**Where does KRNL save downloaded scripts?**  
Scripts added by users are stored in the local `Scripts/User/` directory inside the KRNL folder. Hub content is retrieved from the repository and cached locally.
